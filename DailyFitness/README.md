// DailyFitness

A native iOS strength training app in SwiftUI for following and logging your training program.

## Requirements
- Xcode 16+
- iOS 17+

## Running the App
1. Open the project in Xcode.
2. Set your team and bundle identifier:
   - Select the DailyFitness target, go to Signing & Capabilities.
   - Set a unique Bundle Identifier (e.g. com.yourname.dailyfitness).
   - Choose your Apple Developer Team.
3. Build and run on your iPhone or simulator.
rmca
## Features
- Onboarding: Choose program, start date, and units
- Full logging for all program exercises
- Progress tracking and CSV export
- No third-party dependencies, all data is on-device

## Testing   
- Run tests via the Product > Test menu (Command-U)

## Reset Data
- You can reset all user data from the Settings tab.
